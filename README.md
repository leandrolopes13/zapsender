# ZapSender Pro

Extensão independente para organizar campanhas no WhatsApp Web.

## Funcionalidades

- Cadastro manual e importação de números por CSV/TXT.
- Mensagens com formatação e anexos de imagem.
- Campanhas salvas com nome único, edição, carregamento e exclusão.
- Preferências de envio persistidas no navegador.
- Seleção de grupos, contatos e etiquetas quando disponível e licenciada no plano Pro.
- Relatórios locais e agendamento local exclusivo do Pro.
- Validação de licença por chave.
